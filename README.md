# DND-Reference
dnd-reference è una web app che permette ai tuoi giocatori di DND di acecdere
rapidamente alle schede degli incantesimi, a oggetti magici, alle schede dei
mostri


## Avvio rapido
python3 -m http.server 8080

Apri poi:
http://localhost:8080

Data build: 2026-04-10
