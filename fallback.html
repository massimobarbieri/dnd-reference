Fallback locale per ripristinare il caricamento dei dati

Dati non disponibili

L'app usa i JSON nel submodule locale data. Se questa pagina appare dopo un errore di caricamento, il submodule potrebbe non essere stato inizializzato oppure il sito potrebbe essere aperto con file://.

Da root del progetto esegui:

git submodule update --init --recursive
python3 -m http.server 8080

Quindi apri http://localhost:8080.
